# Инструкция по запуску и использованию

## Требования
- Python 3.8+ (проверено на 3.12). Сторонние библиотеки не нужны.
- Windows: если в консоли появляются «кракозябры», выполните `chcp 65001` или задайте `set PYTHONIOENCODING=utf-8`.

## Структура
```
данные/      организация.py, карта_данных.py, нарушения.py, страны.py, заявки_на_передачу.py, документы/*.txt
программы/   проверка_согласия.py, проверка_страны.py, проверка_заявки.py,
             создание_уведомления.py, расчёт_штрафа.py, главный_симулятор.py
отчёты/      создаются при запуске
```

## Запуск (из папки «Лабораторная работа 3»)

Главный симулятор:
```
python программы/главный_симулятор.py
```
Он проверяет данные и документы, пишет `отчёты/итоговый_отчёт.txt` и ждёт ваши фразы. Выход: `выход` (или `exit`, `q`).

Отдельные программы:
```
python программы/проверка_согласия.py   -> отчёты/отчёт_по_согласиям.txt
python программы/проверка_заявки.py      -> отчёты/отчёт_по_передаче.txt
python программы/проверка_страны.py      (демо для IL, CN, UA, ZZ)
python программы/расчёт_штрафа.py        (демо расчёта)
python программы/создание_уведомления.py (создаёт отчёты/уведомление_пример.txt)
```

## Как формулировать запросы
Пишите обычным русским языком. Симулятор ищет:
- **Действие:** «передать / передача / отправить» → передача; «утечка / взлом / инцидент» → происшествие.
- **Страну:** название в любом падеже (Китай, в США, Израиль, Бразилию). Список — `данные/страны.py`.
- **Число людей:** `20 000`, `5000`, `100 тысяч`.
- **Вид данных:** «биометрические / ДНК / геном» → биометрические; «здоровье / медицинские» → специальные; иначе «иные».
- **Повторность:** слова «повторная», «снова», «опять».

Примеры:
```
Хотим передать данные 20 000 клиентов в Китай для аналитики
Обнаружена утечка 3 000 геномных профилей из базы в США
Повторная утечка 200 000 записей из базы в США
```
После каждого запроса отчёт перезаписывается и накапливает все запросы сессии. При утечке создаётся `отчёты/уведомление_последнее.txt`.

## Как получить 5 сценариев для отчёта
Запускайте симулятор заново для каждого запроса и сохраняйте `итоговый_отчёт.txt` под своим именем. Готовые копии лежат в `отчёты/сценарии/`.

## Что настроить перед сдачей
1. `данные/организация.py`: `ПОРЯДКОВЫЕ_НОМЕРА = (0, 0)` замените на ваши номера по списку. Число людей считается как 300 000 + группа + сумма номеров.
2. Реквизиты в документах (ИНН, адрес, e-mail) — вымышленные, замените при необходимости.
3. Законодательные нормы и штрафы сверьте с актуальным КоАП и приказом Роскомнадзора № 128.

## Типичные ошибки
- `ОШИБКА ЗАГРУЗКИ: ...` — в файле данных не хватает поля или нарушена структура (например, сумма людей по отделениям не равна общему числу). Исправьте указанный файл.
- «Страна не распознана» — добавьте страну в `данные/страны.py` или укажите её иначе.
- «Не удалось определить действие» — используйте слова «передать» или «утечка».
