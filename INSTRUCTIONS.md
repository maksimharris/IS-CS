# Инструкция: запуск, устройство и проверка

## 1. Подготовка
- Python 3.8+ (проверено на 3.12), сторонние библиотеки не нужны.
- Все команды выполняются из корневой папки проекта («Лабораторная работа 3»).
- Если в консоли Windows вместо русских букв «кракозябры»: `chcp 65001`, затем `set PYTHONIOENCODING=utf-8`.

## 2. Структура
```
data/
  organization.py       паспорт организации (словарь `organization`)
  data_map.py           карта данных (словарь `data_map`, 16 записей)
  violations.py         три заложенных нарушения (словарь `violations`)
  countries.py          справочник 23 стран (словарь `countries`)
  transfer_requests.py  три заявки на передачу (список `requests`)
  documents/            employee_consent.txt, client_consent.txt, policy.txt, breach_notification.txt
programs/
  consent_check.py      проверка согласий (задание 2.2)
  country_check.py      проверка страны (3.2)
  request_check.py      проверка заявок (3.3)
  notification_builder.py  создание уведомления в РКН (4.1)
  fine_calculator.py    расчёт штрафа (4.2)
  main_simulator.py     главный симулятор (раздел 5)

```

## 3. Как работает комплекс (схема)
1. **Данные** лежат в `.py`-файлах как словари и списки. Программы подключают их через `import`, а не хранят внутри себя.
2. **Главный симулятор** (`programs/main_simulator.py`) работает по шагам:
   - **Шаг 1.** Загружает организацию, карту данных, нарушения, страны, заявки. Проверяет полноту: все поля паспорта, сумма людей по отделениям = общему числу, в карте ≥ 15 записей и допустимые виды данных, ровно 3 нарушения, ≥ 20 стран, 3 заявки. При проблеме печатает `ОШИБКА ЗАГРУЗКИ: ...` и завершает работу.
   - **Шаг 2.** Проверяет все `.txt` из `data/documents/`: согласия — функцией `check_consent`, политику — по объёму (≥ 1500 слов) и обязательным разделам, образец уведомления — по наличию полей.
   - **Шаг 3.** Пересчитывает три нарушения через `calculate_fine` с реальной выручкой из паспорта.
   - **Шаг 4.** Принимает фразу пользователя и разбирает её модулем `re`: страна (в любом падеже), число людей (`20 000`, `5000`, `100 тысяч`), вид данных (геном/ДНК/биометрия → биометрические; здоровье/медицина → специальные; иначе иные), действие (передача или утечка), повторность («повторная», «снова», «опять»).
   - **Шаг 5.** Пишет `reports/final_report.txt`: общие сведения, итоги по документам, нарушения, разбор запросов, итоговая оценка 0–100, общий риск, 3–5 первоочередных действий.
   - **Шаг 6.** Работает в цикле, пока не введено `выход`; отчёт перезаписывается после каждого запроса и накапливает все запросы сессии.
3. **Оценка** = 100 − штрафные баллы. Веса: биометрия 25, неуведомление 15, согласие 10; документ: грубая ошибка 10, замечание 4; утечка малая/средняя/крупная 5/10/15 (+10 за биометрию или повторность, +5 за специальные данные); передача: запрет 8, условия 3.
4. **Приговор по передаче**: страна из справочника → «разрешено» (достаточная защита или Конвенция 108), «разрешено при условиях» (ждать 10 рабочих дней после уведомления РКН), «запрещено» (режим запрета или неизвестный код).
5. **Уведомление**: до 24 часов с обнаружения — первичное, позже — дополнительное (результаты расследования, срок 72 часа).
6. **Штраф**: таблица минимум/максимум по виду нарушения; при повторной утечке или биометрии включается оборотный штраф 1–3 % выручки (нижний предел 20 млн, верхний 500 млн руб.).

## 4. Запуск
Главный симулятор:
```
python programs/main_simulator.py
```
Примеры фраз: `Хотим передать данные 20 000 клиентов в Китай для аналитики`, `Обнаружена утечка 5 000 записей из базы в США`, `Повторная утечка 200 000 записей из базы в США`. Выход: `выход`.

Отдельные программы:
```
python programs/consent_check.py        -> reports/consent_report.txt
python programs/request_check.py        -> reports/transfer_report.txt
python programs/country_check.py        (демо)
python programs/fine_calculator.py      (демо)
python programs/notification_builder.py -> reports/sample_notification.txt
```

## 5. Как проверить каждый раздел

| Раздел | Что сделать | Ожидаемый результат |
|---|---|---|
| **0. Паспорт** | Запустить симулятор (`выход` сразу) и открыть `reports/final_report.txt` | «Людей в базе: 300 047» (300 000 + 31 + 16); выручка 840 000 000 руб. |
| **1.1 Карта данных** | В Python: `import sys; sys.path.insert(0,'data'); from data_map import data_map as k; print(len(k['записи']))` | 16; виды данных только из четырёх допустимых |
| **1.2 Нарушения** | Открыть раздел «3. Найденные нарушения» итогового отчёта | Три нарушения: №1 биометрия (20 млн), №2 уведомление (3 млн), №3 согласие/передача (300 тыс.), у каждого — норма, описание, исправление |
| **2.1 Документы** | Открыть файлы в `data/documents/`; посчитать слова политики | Политика ≥ 1500 слов (1596), есть все разделы; согласия — отдельные документы |
| **2.2 Согласия** | `python programs/consent_check.py` | Оба согласия «в порядке», штраф 0; создан `reports/consent_report.txt`. Негативный тест: добавьте в `data/documents/client_consent.txt` фразу «в соответствии с договором» и перезапустите — состояние «грубая ошибка», штраф ≥ 300 000, не больше 700 000. Верните текст обратно |
| **3.1 Страны** | `python programs/country_check.py` и посчитать ключи: `from countries import countries; len(countries)` | 23 страны, ключи из двух латинских букв, у каждой пять полей плюс режим |
| **3.2 Проверка страны** | Демо `country_check.py` | IL — «разрешено», 0 дней; CN — «разрешено при условиях», 10 дней; UA — «запрещено»; ZZ — «запрещено» (неизвестная) |

| **4.1 Уведомление** | `python programs/notification_builder.py` | Файл `reports/sample_notification.txt`, вид «дополнительное» (прошло > 24 ч), заполнены все поля |

Негативный тест: временно удалите из словаря в `data/organization.py` ключ `"отрасль"` и запустите — будет `ОШИБКА ЗАГРУЗКИ: в паспорте организации нет поля «отрасль»`; верните ключ обратно |

### Быстрый чек всего комплекса одной командой
```
python programs/consent_check.py && python programs/request_check.py && python programs/notification_builder.py && python programs/fine_calculator.py
```
Если не появилось сообщений об ошибках и созданы файлы в `reports/`, то всё работает. Затем запустите симулятор.

## 6. Типичные проблемы
- `ОШИБКА ЗАГРУЗКИ: ...` — в файлах данных не хватает поля или нарушена структура (имя файла и причина указаны в сообщении).
- «Страна не распознана» — укажите страну иначе или добавьте её в `data/countries.py`.
- «Не удалось определить действие» — используйте слова «передать» или «утечка».
- При открытии отчёта Word предлагает обновить поля — согласитесь, чтобы обновилось оглавление.
- Число людей меняется только в `data/organization.py` (`GROUP_NUMBER`, `LIST_NUMBERS_SUM`).
