# Инструкция по запуску и использованию

## Требования
- Python 3.8+ (проверено на 3.12). Сторонние библиотеки не нужны.
- Windows: если в консоли появляются «кракозябры», выполните `chcp 65001` или задайте `set PYTHONIOENCODING=utf-8`.

## Структура
```
data/      organization.py, data_map.py, violations.py, countries.py, transfer_requests.py, documents/*.txt
programs/   consent_check.py, country_check.py, request_check.py,
             notification_builder.py, fine_calculator.py, main_simulator.py
reports/      создаются при запуске
```

## Запуск (из папки «Лабораторная работа 3»)

Главный симулятор:
```
python programs/main_simulator.py
```
Он проверяет данные и документы, пишет `reports/final_report.txt` и ждёт ваши фразы. Выход: `выход` (или `exit`, `q`).

Отдельные программы:
```
python programs/consent_check.py   -> reports/consent_report.txt
python programs/request_check.py      -> reports/transfer_report.txt
python programs/country_check.py      (демо для IL, CN, UA, ZZ)
python programs/fine_calculator.py        (демо расчёта)
python programs/notification_builder.py (создаёт reports/sample_notification.txt)
```

## Как формулировать запросы
Пишите обычным русским языком. Симулятор ищет:
- **Действие:** «передать / передача / отправить» → передача; «утечка / взлом / инцидент» → происшествие.
- **Страну:** название в любом падеже (Китай, в США, Израиль, Бразилию). Список — `data/countries.py`.
- **Число людей:** `20 000`, `5000`, `100 тысяч`.
- **Вид данных:** «биометрические / ДНК / геном» → биометрические; «здоровье / медицинские» → специальные; иначе «иные».
- **Повторность:** слова «повторная», «снова», «опять».

Примеры:
```
Хотим передать данные 20 000 клиентов в Китай для аналитики
Обнаружена утечка 3 000 геномных профилей из базы в США
Повторная утечка 200 000 записей из базы в США
```
После каждого запроса отчёт перезаписывается и накапливает все запросы сессии. При утечке создаётся `reports/last_notification.txt`.

## Как получить 5 сценариев для отчёта
Запускайте симулятор заново для каждого запроса и сохраняйте `final_report.txt` под своим именем. Готовые копии лежат в `reports/scenarios/`.

## Что настроить перед сдачей
1. `data/organization.py`: `ПОРЯДКОВЫЕ_НОМЕРА = (0, 0)` замените на ваши номера по списку. Число людей считается как 300 000 + группа + сумма номеров.
2. Реквизиты в документах (ИНН, адрес, e-mail) — вымышленные, замените при необходимости.
3. Законодательные нормы и штрафы сверьте с актуальным КоАП и приказом Роскомнадзора № 128.

## Типичные ошибки
- `ОШИБКА ЗАГРУЗКИ: ...` — в файле данных не хватает поля или нарушена структура (например, сумма людей по отделениям не равна общему числу). Исправьте указанный файл.
- «Страна не распознана» — добавьте страну в `data/countries.py` или укажите её иначе.
- «Не удалось определить действие» — используйте слова «передать» или «утечка».
